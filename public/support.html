Getting help

Better PDF Export is open source and maintained on GitHub. Please report problems and ask questions there:

github.com/Rakantor/word-better-pdf-export/issues

When reporting a problem with a specific document, include the text from the Picture details and Log sections of the task pane. They list every picture in the PDF and what happened to it. Remove private names and content from logs before posting. Attach only documents you can share publicly.

Frequently asked questions

A picture was not replaced. Why?

The pane tells you the reason for each picture:

  • Skipped – picture effect: the picture uses recolouring, brightness/contrast, transparency, artistic effects or soft edges. Word bakes these into the exported bitmap, so replacing it would remove the effect.
  • Skipped – already lossless / original bytes: Word exported this picture without loss; nothing to improve.
  • Left as is – not matched: no picture in the document looks like this image (for example a linked picture whose file is not embedded, or an image Word generated itself).

The PDF is much larger than before.

That is expected: the original pictures are embedded at full size. A 12 MB photo makes the PDF about 12 MB larger. Downsize pictures in Word beforehand if you need a smaller file.

Does it work in Word on the web or on iPad?

Word on the web cannot pass the exported PDF to add-ins, so the add-in is not available there. The current installation flow targets Windows and Mac; iPad is not supported by this project.

Is my document sent anywhere?

No. The export and the picture replacement run entirely inside Word's task pane on your computer. See the privacy policy.
