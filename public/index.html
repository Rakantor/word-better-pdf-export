Better PDF Export for Word

OverviewSupportPrivacyTermsGitHub

Export Word documents to PDF without the picture compression Word applies on its own.

Word's built-in PDF export can downsample and recompress pictures. Better PDF Export still lets Word produce the PDF (using Word’s layout and drawing instructions), then restores matching pictures from the image files stored inside your document.

Everything happens on your computer, inside Word's task pane. Your document is never uploaded anywhere.

How to use it

  1. Open the document in Word for Windows or Mac (Microsoft 365).
  2. On the Home tab, choose Export PDF in the Better PDF Export group.
  3. Click Export PDF with original pictures and choose where to save the file.

The pane shows, for every picture in the PDF, whether it was replaced, skipped or left as is, and why.

Install

The add-in is being prepared for Microsoft Marketplace. Until it is listed there, it can be installed manually on Windows:

  1. Download the manifest: manifest.xml and save it, for example to C:\Users\<you>\Documents\BetterPdfExport\manifest.xml.
  2. Save the following as install.reg, edit the path to match step 1 (backslashes doubled), and double-click it: 
    Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\SOFTWARE\Microsoft\Office\16.0\Wef\Developer]
"03305ea7-f246-41ac-8451-c52f63a8f2ff"="C:\\Users\\<you>\\Documents\\BetterPdfExport\\manifest.xml"
  3. Restart Word. The Export PDF button appears on the Home tab.

To uninstall, delete only the registry value 03305ea7-f246-41ac-8451-c52f63a8f2ff from the key above, restart Word, and remove your downloaded manifest.

On Mac, download the same manifest and follow Microsoft’s sideloading instructions for Word.

What is and isn't changed

ContentResult
Photos and other bitmap picturesMatching pictures restored at their stored resolution (uncropped JPEG bytes verbatim, PNG lossless)
Cropped picturesCropped region taken from the original at full resolution
Pictures with colour/transparency/artistic effectsLeft as Word exported them (the effect is part of Word's rendering)
Text, shapes, charts, SVG/EMF graphicsWord’s drawing instructions retained

Requirements

Word for Windows or Word for Mac with a Microsoft 365 subscription. Word on the web is not supported because it cannot hand the exported PDF to add-ins.

Better PDF Export is an open-source Word add-in. Source code and issue tracker: github.com/Rakantor/word-better-pdf-export.
